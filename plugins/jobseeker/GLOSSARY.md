# Glossary

| Term | Meaning (this plugin) | Not confused with | Notes |
|------|----------------------|-------------------|-------|
| tailor | Rewrite master content toward a specific JD (resume or cover) | Generic “customize tone” | Integrity gates still apply |
| master | Canonical resume / cover components before JD-specific rewrite | Team lead / master’s degree | Prerequisite for tailor flows |
| roast | Critical T14-style pass that flags weak or undefended claims | Comedy insult session | Prompt T14 |
| integrity gate | One of the six exit checks that must PASS before any write | CI quality gate | Never fabricate; interview-defensible metrics |
| bullet formula | Structured achievement line shape (XYZ family default) | Free-form prose bullets | See reference formulas |
| claim | Asserted accomplishment or skill that needs evidence | Legal claim / insurance claim | Flag when JD gap has no evidence |
