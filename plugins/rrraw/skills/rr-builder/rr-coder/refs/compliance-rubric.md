# Coder principles compliance rubric

Stable **Rule IDs** (`CPNNN`) for classifying coder-principles findings. Canonical prose and examples stay in [`code.principles.md`](code.principles.md); this file **indexes** rules and sets default severity plus overrides.

## Rule ID grammar

- **Pattern:** `CP` + **3-digit** number — e.g. **`CP013`**, **`CP025`** (spoken “CP zero-one-three”; written without hyphen or space).
- **Emit in reports and MR inline:** `CPNNN` only — same token in **Rule ID** column and inline body (`CP013: …` or `**CP013** — …`).
- **Forbidden in new output:** `CP-NNN`, `CP NNN`, `#CP013`, bare `013` without the `CP` prefix.
- **Language-specific (v1):** cite the language ref **§heading** until curated `CPLANG…` IDs exist; default severity **Suggestion** unless a principles **`CPNNN`** Fail-if applies or an Escalate bullet matches.

### Legacy alias (readers of old reports only)

| Legacy | Current |
|--------|---------|
| `CP-001` … `CP-026` | `CP001` … `CP026` |
| `CP-13` | `CP013` |

Agents **emit only `CPNNN`**. When posting MR comments from an old report, rewrite `CP-(\d+)` / `CP (\d+)` to zero-padded **`CP` + 3 digits** (e.g. `CP-13` → `CP013`) per [`mr-review-findings-inline.md`](../../../gitlab/gitlab-workflow/refs/mr-review-findings-inline.md) Step 2b.

## Classification procedure

Coding-lane enforcement (MUST / Fail-if evidence / Challenge / bias demote): [`severity-triage.md`](severity-triage.md) (loads shared schema). Precedence there overrides soft “check demote” wording below when they conflict.

0. **Maintenance-hunk exclusion** — Before **`CPNNN`** mapping, apply [`maintenance-hunk-exclusion.md`](../../rr-review/refs/maintenance-hunk-exclusion.md). If any drop rule matches → **drop** (no row at any severity); do not continue steps 1–9 for that observation.
1. **Load** this rubric together with [`code.principles.md`](code.principles.md) (and language refs per code-skill when reviewing).
2. **Observe** a concrete issue in the diff (anti-pattern, structure, boundary, comment, etc.).
3. **Map** the observation to the **single best-fit** `CPNNN` row (if two rows apply, pick the more specific; if still tied, prefer the row whose *Fail if* matches first). When the change **adds or changes a public field** on a shared contract, cross-read **all sibling fields** before mapping — prefer **CP027** for cohesion/tunability; **CP010** if the field duplicates an existing delegation path; **CP025** if the value is implementation-intrinsic leaking across boundaries. When the issue is log shape/safety/levels/tooling/noise, missing or vanity meters on critical boundaries, or correlation/cardinality, map via [`observability.md`](observability.md) to **CP028** / **CP029** / **CP030** (swallow-vs-rethrow stays **CP007**).
4. **Reject map if Fail if does not match** — Observation **MUST** literally match the row’s *Fail if*. If not → **MUST NOT** emit that `CPNNN` as Critical/Warning (drop, or Suggestion **without** that ID). Docs/ADR/markdown examples → **MUST NOT** map Prefer/Avoid code IDs (esp. **CP003**, **CP004**).
5. **Do not flag** when a **Do not flag** bullet applies (or when the issue is purely language-specific with no principles row — then cite the language ref heading and default **Suggestion** unless a `CPNNN` Fail-if still applies). Matching Do-not-flag → **drop** (no row).
6. **Check** **Pass if** / **Demote to Suggestion when** — if any bullet matches, lower to **Suggestion** or Pass/drop (cannot demote below Suggestion; **MUST NOT** keep as Warning).
7. **Check** **Escalate to Critical when** — only if Fail-if matched and no Do-not-flag / Demote / Pass-if cleared it; then raise to **Critical**.
8. **Assign severity** = **Default severity** for that ID only after steps 4–7.
9. **Emit** the finding with **Rule ID**, file, line(s), short **quoted snippet**, and rationale tied to *Fail if* / *Pass if* (coding lane: Fail-if evidence per [`severity-triage.md`](severity-triage.md)).

**Evidence:** Each finding must include **Rule ID**, **line number(s)**, and a **short quoted snippet** from the diff or file.

## Language-specific violations

Refs such as `java.md`, `typescript.md`, etc. are **not** fully enumerated here in v1. Use the pattern `CPLANG<ref>NNN` only when those refs later define curated IDs. Until then: cite the **§heading** (or section) in the language ref, default severity **Suggestion** unless a principles rule (`CPNNN`) Fail-if clearly applies or an Escalate bullet matches.

## Severity reference

- **Critical**: Default only where indicated; **escalation** bullets can raise other IDs to Critical. Merge/gate blockers align with [`docs/REVIEW.md`](../../../../docs/REVIEW.md) and coding-lane workflows.
- **Warning / Suggestion**: Use **Demote to Suggestion** when a bullet matches; coding lane **MUST** apply [`severity-triage.md`](severity-triage.md) precedence. Soft vs hard IDs: that ref.
